## What’s new

- Writing review with Langdock: add your Langdock API key in Settings → Connections, choose a model, and use Review now from the document menu. Up to three comments appear in floating cards beside their passages, with optional rewrites. Rewrites apply only when you accept them and can be undone.
- Reviews are saved per draft; new branches start with their own history. Editing the draft marks earlier suggestions as out of date.
- Type `/` to insert headings, lists, checkboxes, quotes, dividers, code, links and images from a grouped menu, in the editor and the stash.
- Add or toggle a checkbox with Writing → Checkbox (Shift-Command-L), or type `[ ] ` at the start of a line. Checkboxes are now softly rounded and filled.

Only the active draft’s title, goal and text are sent to Langdock, and only when you request a review.
