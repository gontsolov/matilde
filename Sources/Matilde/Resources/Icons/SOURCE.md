# Tabler Icons

Interface icons from Tabler Icons, release `v3.52.0`:

https://github.com/tabler/tabler-icons/tree/v3.52.0/icons

The unmodified SVGs are in `assets/tabler-icons/` (`outline/` and `filled/`). `scripts/tabler-icons.py` converts them to these single-page vector PDFs, redrawing outline strokes at 1.5 instead of Tabler's default 2 on the 24-point grid. Filled variants end in `-filled`.
