matilde: I like knowing who else is in the room.

If you've connected an AI tool like Claude or ChatGPT to your notes, you can now see it, and stop it, right in Settings.

- Settings → Sync lists each connected AI tool: what it may do, when its access ends and when it was last used.
- Choose Disconnect next to a tool and it stops at once.
- A comment left by an AI tool shows which tool it came from.
- While a tool is connected, Settings says so plainly: the Matilde server can then decrypt your notes for that tool. Without one, your notes stay end-to-end encrypted.
- Matilde now looks for updates through matilde.page. Each check is counted anonymously, and nothing else is sent.
