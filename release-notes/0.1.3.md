## What's new

- A welcoming first document introduces branching, the canvas, Markdown, images, and links. Reopen it from Help → Welcome to Matilde.
- Paste images into your writing. Images stay local and remain available across branches.
- Pasted URLs become clickable. Paste a URL over selected words to link them, or use Command-K to add or edit a link.
- Type `---` on its own line for a subtle divider, with full-line selection and improved cursor navigation.

## A quieter writing space

- A dotted canvas with cleaner previews that omit writing goals.
- Smoother, speed-limited document zoom with a snappier release.
- Wrapped titles grow downward without shifting the header upward.
- Automatic red spelling underlines are off; manual spelling tools remain available.

Images currently render from local Markdown references; remote image fetching and rich URL preview cards are not included. Keep the workspace's hidden `.assets` folders with your Markdown files when moving or backing up image-containing writing.
