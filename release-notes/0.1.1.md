## What's changed

- Bold and italic shortcuts now toggle formatting off as well as on, preserving Unicode selections.
- Return continues lists and checkboxes, but leaves fenced code blocks alone and avoids duplicating markers at the start of a line.
- Fixed an overflow with very large numbered-list values.
- Fixed an opening-time race that could ignore typing while restoring the editor's scroll position.
- Checkbox clicks now have to land on the checkbox itself.

Verified with editor interaction, undo/redo, paste, formatting, and persistence tests.
